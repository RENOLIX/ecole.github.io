# Les Génies du Calcul Mental

Site vitrine de l’école de calcul mental et soroban située au 22 rue Méhul, 93500 Pantin.

Site public : https://renolix.github.io/ecole.github.io/

Les sept pages statiques se trouvent dans `docs/`. GitHub Pages est configuré pour publier la branche `main` depuis `/docs`. Le script `node build.mjs` régénère les pages HTML dans `docs/`. Le CSS, le JavaScript et les médias sont également dans `docs/`.

Le formulaire prépare un message WhatsApp. Il ne stocke pas les données et n’envoie pas de message automatiquement. L’utilisateur contrôle l’envoi dans WhatsApp.

Les tranches d’âge affichées servent de repères pédagogiques. Les horaires, tarifs et modalités d’inscription restent à confirmer auprès de l’école. Les résultats Euro Maths 2026 proviennent des informations fournies par le client.

Les quatre photos et les deux vidéos sont une sélection des médias fournis. Le logo fourni a été détouré. La police Manrope est distribuée localement avec sa licence SIL OFL dans `docs/assets/`.
